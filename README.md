# Maison Hygia — AI Ritual Concierge

An intelligent, need-driven discovery system built for **Maison Hygia Global Talent Fellowship 2026** (Case Study 3: AI & Innovation)[cite: 2]. 

The system transitions e-commerce discovery from traditional keyword search into lifestyle-grounded conversational ritual curation[cite: 2]. It decomposes multi-variable user intent, dynamically scores product candidates, enforces regulatory compliance, and pairs primary routine steps with tailored botanical alternatives[cite: 2, 5].

## 📌 Problem Scenario
**User Query:** *"My skin feels dry lately, I'm not sleeping particularly well, and I want to create a better evening routine without making it complicated."*[cite: 2]

### Key Challenges
1. **Multi-Intent Parsing:** Simultaneously resolving dermatological barrier replenishment, circadian/sleep wellness, and routine simplicity constraints[cite: 2, 5].
2. **Regulatory Overreach:** Preventing generative AI hallucinations from making prohibited medical claims (e.g., "cures insomnia" or "treats eczema") under FDA/FTC cosmetics and dietary supplement guidelines[cite: 2, 5].
3. **Predatory Margin Skew:** Preventing the recommendation engine from defaulting to complex, high-margin treatments that degrade customer trust and lead to routine abandonment[cite: 2, 5].
